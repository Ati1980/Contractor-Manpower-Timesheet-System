# ระบบบันทึกชั่วโมงการทำงานผู้รับเหมา (Contractor Manpower & Working Hours System)

ระบบแบบฟอร์มบันทึกชั่วโมงการทำงานผู้รับเหมา สำหรับฝ่ายความปลอดภัย อาชีวอนามัย และสิ่งแวดล้อม (จป.) และฝ่ายบริหารแรงงาน

## ฟังก์ชันการทำงานหลัก

1. **รองรับ 5 บริษัทผู้รับเหมา**:
   - บริษัท รักษาความปลอดภัย ที.เจ.เซอร์วิส กรุ๊ป จำกัด (กลุ่ม รปภ.)
   - บริษัท รักษาความปลอดภัย ที.เจ.เซอร์วิส กรุ๊ป จำกัด (กลุ่มธุรการ-โยธา)
   - บริษัท ไอเอฟเอส ซัพพอร์ต เซอร์วิสเซส จำกัด
   - บริษัท รักษาความปลอดภัย ที.เจ.เซอร์วิส กรุ๊ป จำกัด
   - บริษัท โสจิรพันธุ์ จำกัด

2. **2 รูปแบบการกรอกข้อมูล (Dual Input Modes)**:
   - **ตารางบันทึกเวลางวดงาน (Timesheet Matrix)**: บันทึกแบบชุดทั้งงวด (1-15, 16-สิ้นเดือน, ทั้งเดือน) พิมพ์ 8 หรือ 12 ในช่องเหมือน Excel พร้อมคำนวณ Normal & OT ทันที และเลื่อนช่องด้วยปุ่มลูกศร
   - **ฟอร์มกรอกรายบุคคล / รายวัน (Single Entry)**: ค้นหาพนักงานด้วยรหัสหรือชื่อ แสดงโปรไฟล์และสถานะการอบรม จป. พร้อมปุ่มเลือกกะ (8 ชม., 12 ชม., 10 ชม., วันหยุด) และปุ่ม "บันทึกและกรอกคนถัดไป"

3. **กฎการคำนวณชั่วโมงทำงาน (Calculation Rules)**:
   - กะปกติ 8 ชม. = ชม.ปกติ 8 ชม., OT 0 ชม.
   - กะ 12 ชม. (รปภ. / กองใบอ้อย) = ชม.ปกติ 8 ชม., OT 4 ชม.
   - ชั่วโมงรวมเกิน 8 ชม. จะถูกคิดเป็น OT โดยอัตโนมัติ

4. **ทะเบียนพนักงานและความปลอดภัย (Safety Induction Roster)**:
   - มีฐานข้อมูลเริ่มต้น 86 คน (TJ001 - TJ086)
   - ตรวจสอบสถานะการอบรมปฐมนิเทศความปลอดภัยก่อนเข้างาน (trained, train 3 hrs., Not)
   - เพิ่ม / แก้ไข / ลบ ข้อมูลพนักงานได้

5. **รายงานสรุป จป. และการส่งออกข้อมูล**:
   - สรุปจำนวนพนักงานเข้าทำงานแยก ชาย / หญิง / รวม
   - สรุปชั่วโมงทำงานและ OT เปรียบเทียบรายเดือนตลอดปี 2569 (2026)
   - สรุปรายสัปดาห์ (Week 1 - 53)
   - ส่งออกเป็นไฟล์ CSV (รองรับภาษาไทยใน Microsoft Excel)
   - รองรับการสั่งพิมพ์ (Print Layout) พร้อมช่องลงลายมือชื่อ

## วิธีเปิดใช้งาน

1. ดับเบิลคลิกเปิดไฟล์ `index.html` ใน Google Chrome หรือ Microsoft Edge เพื่อเริ่มใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม
2. หรือรัน Local Web Server ด้วยคำสั่ง:
   ```bash
   python -m http.server 8080
   ```
   แล้วเปิดบราวเซอร์ไปที่ `http://localhost:8080`
